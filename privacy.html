Privacy

VoidWalkr is a static web app. The whole thing is HTML, CSS, and JavaScript served from a CDN. It does not run a backend, does not have a database, and does not require an account.

What we collect

Nothing. We do not set cookies. We do not run analytics. We do not fingerprint your browser.

Local storage

Your selected theme is stored in your browser's localStorage (key voidwalkr.theme) so the site remembers it next visit. It never leaves your device.

Third parties

VoidWalkr is free, ad-free, and collects no data. There are no ad networks, no third-party trackers, and no analytics cookies on this site.

The site is hosted on GitHub Pages. GitHub serves the static files and, like any web host, may process IP addresses in order to deliver them. See GitHub's privacy statement for details. VoidWalkr itself runs no analytics of any kind.

When you watch a video, the YouTube IFrame API loads on YouTube's servers. Your viewing is subject to Google's privacy policy.

The home page shows a small Ko-fi widget so visitors who find the site useful can support it. The widget loads from ko-fi.com; if you interact with it (click the button), Ko-fi's own cookie and privacy policies apply. VoidWalkr itself sets no cookies and collects no data.

Contact

VoidWalkr collects no data from visitors, so there is no user information to delete, export, or modify. If you have a question about the service, the source is self-contained and the answer is always in the code itself.

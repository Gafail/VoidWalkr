Privacy

VoidWalkr is a static web app. The whole thing is HTML, CSS, and JavaScript served from GitHub Pages. It does not run a backend, does not have a database, and does not require an account.

What we collect

Nothing. VoidWalkr itself does not set cookies, run analytics, or fingerprint your browser. The one thing it stores is your selected theme, in localStorage, on your own device.

Local storage

Your selected theme is stored in your browser's localStorage (key voidwalkr.theme) so the site remembers it next visit. It never leaves your device.

Third parties

VoidWalkr is free. It runs no ad networks and no third-party trackers of its own. Two third parties are loaded by the site, though, and they behave according to their own policies:

The site is hosted on GitHub Pages. GitHub serves the static files and, like any web host, may process IP addresses in order to deliver them. See GitHub's privacy statement for details. VoidWalkr itself runs no analytics of any kind.

When you watch a video, the YouTube IFrame API loads on YouTube's servers. YouTube may set its own cookies, serve its own ads inside the embedded player, and perform its own logging — that is YouTube's doing, not VoidWalkr's, and it happens whether or not you click anything on the embedded player. Your viewing is subject to Google's privacy policy.

The home page shows a small Ko-fi widget so visitors who find the site useful can support it. The widget's script is fetched from Ko-fi's servers (storage.ko-fi.com) as soon as the page loads, and it pulls in a web font from Google Fonts — so Ko-fi's and Google's privacy policies apply from that point, not only after you click the button. VoidWalkr itself still sets no cookies and collects no data.

Contact

VoidWalkr collects no data from visitors, so there is no user information to delete, export, or modify. If you have a question about the service, the source is public and the answer is usually in the code — github.com/Gafail/VoidWalkr.
